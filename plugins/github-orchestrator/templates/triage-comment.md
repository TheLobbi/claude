# Triage Comment Templates

Used by `issue-triager` and `dedup-detective`. Issue comments are read by the
person who took the time to file. Be direct and useful, never dismissive. Never
guess at a reporter's pronouns — use their handle.

Every comment ends with the attribution footer.

---

## Needs more information

Ask for exactly what is missing, as specific questions. A template dump gets
ignored; a specific question gets an answer.

```markdown
Thanks for the report — the stack trace narrows this down a lot.

Two things would let me reproduce it:

1. Which Node version? (`node --version`)
2. Does it happen with an empty cart, or only when a promo code is applied?

Marking this `needs-info` in the meantime; it goes straight back in the queue
once you reply.

---

```

## Duplicate

Name what matched. A bare link reads as a brush-off and gives the reporter no
way to disagree.

```markdown
This looks like the same defect as #188 — same `TypeError` at
`CartSummary.tsx:44`, same trigger (empty cart with a promo code applied).

Closing as a duplicate and carrying your reproduction steps over to #188, since
yours is more precise than what's there. Follow #188 for the fix.

---
_Generated by [Claude Code](https://claude.ai/code)_
```

## Possibly related

Use this whenever confidence is medium. Closing a distinct bug as a duplicate
loses it entirely — the reporter stops following and nobody re-files.

```markdown
Possibly related to #188 — same endpoint, and both started after 2.4.0. The
symptoms differ enough that I'm leaving this open; if the fix for #188 resolves
it, we'll close it then.

---
_Generated by [Claude Code](https://claude.ai/code)_
```

## Proposed closure (stale)

Never close silently. Propose, with the reason, and leave the door open.

```markdown
This has had no activity for 214 days and there's no reproduction on file, so
I'm proposing we close it as `not_planned`.

If it's still happening, reply with a reproduction and it reopens — no need to
file a new issue.

---
_Generated by [Claude Code](https://claude.ai/code)_
```

---

## Never post

- Details of an unpatched security vulnerability. Security reports leave the
  public path entirely — no public label, no detail in a comment.
- A credential value, even a suspected one.
- Customer identifiers or unredacted production traces.
